# receipt-scanner OCR 店名抽出修正（ドンキ様式＋チェーン正規化・Tier S）

**日付**: 2026-06-28 / **ティア**: S（prompt＋チェーン正規化のみ・DB/RLS/migration/金額/認可 非接触）

## 背景・依頼
オーナー報告「酒類(リカマン/カクヤス)で自社店舗名が店名になりエラー」「ドンキ・ライフが読めない」。
freee に手作業修正して登録済みの実レシートを取得し、実データで検証してから修正。

## 検証手法（ローカル完結・freee/本番DB 非接触）
- freee 取引先からリカマン/カクヤス/やまや/なかやま/ドンキ/ライフの取引を辿り、添付レシート画像 **41枚** を取得（`GET /api/1/receipts/{id}/download?company_id=` が正解DL経路。`file_src` の `/api/p/` は OAuth 不可）。
- ハーネス `ocr-harness.mjs`: 本物の `RECEIPT_PROMPT_V35` と `normalizeStoreName` を import、本番 process.js の判定（normalize→除外→必須項目→confidence→denylist）を再現し、店名抽出と done/error を実測。Anthropic API 直接呼び（claude-sonnet-4-5）。receipt-scanner の登録経路・pending パイプラインは一切起動せず＝**freee 重複登録は構造的に不可能**。

## ベースライン実測（現行プロンプト・41枚）
| カテゴリ | 正解 | エラー化 | 別店名に高信頼誤読 |
|---|---|---|---|
| 酒類(リカマン/カクヤス/やまや/なかやま) | 23/23 | 0 | 0 |
| ライフ | 6/6 | 0 | 0 |
| **ドンキ** | **3/12** | 5(null/medium) | **4(無印良品/餃子の王将/ファミリーマート/AEON)** |

→ **酒類の自社店舗名誤判定は現行プロンプトでは再現せず**（KITUNE 宛名のカクヤス・金魚宛名のリカマンも正読）。旧プロンプト時代の事象か、エラーで freee 未送信＝画像が残っていない別個体と推定。**真の問題はドンキ**で、特に発行者小印字を読めず別チェーンを高信頼で創作する危険な挙動。

## ドンキ失敗の機序（実画像で確定）
ドンキ正式領収証は固定様式: 大見出し「領収証」＋宛名空欄(「様」のみ)＋合計¥＋**左下に小印字で発行者**「(株)ドン・キホーテ／本社 東京都目黒区青葉台2-19-10／◯◯店／TEL 0570-017-611 or 0570-550-702」、明細は右側に90度回転、店頭ロゴ無し。発行者が小さく読めない＋暗い/小さい写真で、別チェーンを創作。

## 修正
1. **prompt.js**: パターンF「ドン・キホーテ系 領収証様式」追加。様式特徴＋判定ルール（読めれば採用/本社住所・TEL 0570-017/550 でドンキ確定/**判読不能時は別チェーン創作禁止→null+medium**/写真不鮮明時も同様）。
2. **process.js** STORE_NORMALIZATION_RULES: `donki /ドン[・･\s]?キホーテ/→'ドン・キホーテ'`、`kakuyasu /カクヤス/→'カクヤス'`（ともに replaceMode:'full'）。freee 取引先の分裂（カクヤス3・ドンキ2）を今後統一。

## 修正後実測（同41枚）
- 酒類 23/23・ライフ 6/6 = **回帰ゼロ**。カクヤス3表記→「カクヤス」統一を確認。
- ドンキ: 危険な高信頼誤読 **4→実質0**。内訳: ドンキ高信頼正読4 / faint は「ドン・キホーテ」medium→手動安全弁（誤った取引先での自動登録が消滅）/ 残2件(イオンフードスタイル¥583・肉のハナマサ¥9190)は**画像が実際にその店＝OCR正解**で、freee 取引先がドンキに誤登録されていた個体（データ衛生の別件）。

## 副産物の発見
freee に取引先の誤登録が混在（AEON/イオンフードスタイル・肉のハナマサがドンキ枠に）。コードでなくデータ衛生。オーナー報告のみ・freee は変更しない。

## 残・申し送り
- EXCLUDED_STORES の部分一致は `ヤマト`→ヤマト運輸、`LR`(2文字) 等の過検出が latent risk（今回は酒類が再現せず触らず）。自社発行領収証の取りこぼし防止と両立する精密化は別途設計。
- ドンキ faint 個体の高信頼化は安全上あえて狙わない（medium→手動が安全）。
- 酒類の自社店舗名エラーの実個体があればサンプルを頂いて追検証。
